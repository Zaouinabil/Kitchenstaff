# Contexte métier du projet Kitchenstaff

## 1. Origine du projet

Le projet Kitchenstaff est inspiré d’une expérience réelle dans le secteur horeca, plus précisément dans un restaurant à Knokke. L’idée vient de l’organisation du travail en cuisine avant le début du service.

Dans ce type de restaurant, une partie importante du travail se fait le matin ou pendant la préparation avant le service. Cette phase est appelée la mise en place. Elle permet de préparer les produits, les sauces, les légumes, les salades et les éléments nécessaires pour que le service se déroule correctement.

L’objectif du projet est de créer une application simple qui aide l’équipe de cuisine à organiser ces préparations.

---

## 2. Organisation de l’équipe

Dans le contexte observé, l’équipe de cuisine est composée de plusieurs postes :

- cuisine froide : environ 6 personnes ;
- cuisine chaude : environ 3 personnes avec le chef ;
- friteuse : 1 personne.

Le projet se concentre principalement sur la cuisine froide, car beaucoup de tâches de mise en place y sont réalisées chaque jour.

---

## 3. Problème observé

Avant le service, plusieurs préparations doivent être réalisées en même temps. Les tâches sont nombreuses et peuvent varier selon le jour, la météo, l’affluence ou les produits disponibles.

Exemples de problèmes possibles :

- certaines tâches peuvent être oubliées ;
- plusieurs personnes peuvent travailler sur la même chose sans coordination ;
- le chef doit souvent vérifier oralement l’avancement ;
- il n’est pas toujours évident de savoir ce qui est déjà terminé ;
- l’organisation dépend beaucoup de l’expérience de l’équipe.

L’application vise à rendre cette organisation plus claire grâce à une liste de tâches simple et partagée.

---

## 4. Exemples de tâches réelles

Les tâches observées concernent surtout la préparation des salades, des légumes, des sauces et du salad bar.

### Salades et salad bar

Exemples :

- préparer la salade verte ;
- organiser le salad bar ;
- préparer les œufs ;
- cuire les œufs ;
- cuire les haricots ;
- préparer les éléments pour les assiettes froides.

### Légumes

Exemples :

- couper les tomates en rondelles ;
- préparer les tomates au four pour les tomates crevettes ;
- préparer les oignons ;
- préparer les choux blancs ;
- préparer les choux rouges ;
- râper les carottes ;
- couper les citrons.

### Sauces

Exemples :

- préparer la mayonnaise ;
- préparer la sauce tartare ;
- préparer la sauce vinaigrette ;
- préparer la sauce pour les moules.

La mayonnaise est une préparation importante. Elle peut être préparée en grande quantité, par exemple avec environ 20 litres d’huile et plusieurs ingrédients comme la moutarde, le sel, le poivre et le citron.

### Autres préparations

Exemples :

- préparer le beurre avec une machine spéciale ;
- former le beurre en portions décoratives ;
- préparer les accompagnements pour les plats froids.

---

## 5. Catégories retenues pour la première version

Pour ne pas compliquer le projet au début, trois catégories principales sont retenues :

1. Sauces
2. Salades
3. Légumes

Ces catégories permettent déjà de couvrir une grande partie des tâches quotidiennes de la cuisine froide.

D’autres catégories pourront être ajoutées plus tard, par exemple :

- fromages ;
- charcuteries ;
- moules ;
- nettoyage ;
- garnitures.

---

## 6. Objectif de l’application

L’application Kitchenstaff permet au chef ou à un responsable de créer une liste de tâches de mise en place pour la journée.

Les membres de l’équipe peuvent ensuite :

- consulter les tâches ;
- voir les préparations à faire ;
- commencer une tâche ;
- terminer une tâche ;
- suivre l’avancement global.

Le but n’est pas de remplacer l’organisation du restaurant, mais de l’aider avec un outil simple, clair et rapide.

---

## 7. Limite volontaire de la première version

La première version reste volontairement simple. Elle ne gère pas encore :

- les stocks ;
- les commandes clients ;
- les réservations ;
- les paiements ;
- les statistiques avancées ;
- les prévisions météo.

Ces fonctionnalités pourront être ajoutées dans une version future.

La priorité est de créer un MVP fonctionnel centré sur la mise en place du matin.
